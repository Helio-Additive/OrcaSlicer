## 🎉 What's in this release (everything since v2.4.2)

This version brings parity with [Orca Slicer v2.5.2](https://github.com/OrcaSlicer/OrcaSlicer/releases/tag/v2.5.2), meaning all the newest features of Orca Slicer, plus Helio thermal simulation and optimisation. It also includes everything from Orca Slicer [v2.5.0](https://github.com/OrcaSlicer/OrcaSlicer/releases/tag/v2.5.0) and [v2.5.1](https://github.com/OrcaSlicer/OrcaSlicer/releases/tag/v2.5.1).

## ✨ What's Improved

### 🖨️ Lighter G-code for printing

Optimised results now load back into the slicer with two G-code files:

- **Preview file:** includes the Thermal Quality Index (TQI) data, so you can view thermal performance in the slicer.
- **Print file:** has the TQI comments removed, so it's much smaller and is the one sent to the printer.

**Why:** very large G-code files can overwhelm some printers and cause defects like blobs and zits. The smaller print file helps your optimised file print cleanly.

**How to use both:**

- **Clicking Print plate sends the print file.** This applies whether you click Print plate in the Helio results dialog or the regular Print plate button.
- **Saving the 3MF keeps both files.** Click the save icon in the Helio Enhance results dialog to save a 3MF that contains both. Open it in the slicer any time to preview the TQI data or send the plate to the printer.
- **Helio History has both too.** You can download either version from there (Third-party icon → Enable Helio → History).
- **Export G-code saves the print file only.** Files exported with File → Export G-code have no TQI data. To keep both files, save a 3MF with the save icon in the Helio Enhance results dialog.
- **Running Enhance again builds on the last result.** If you run Enhance again without reslicing, Helio starts from the optimised print file, not the original slice. Reslice first if you want to start over.

### 🔒 Helio jobs are protected while they run

- **You can't switch plates while Assess or Enhance is running.** Previously, switching plates silently cancelled the job. Wait for it to finish, or cancel it first.
- **Changing the printer cancels the running job cleanly.** The job is stopped in Helio as well, so it doesn't keep running in the background.
- **Cancelling responds immediately.** The app no longer freezes while a cancel waits for Helio.
- **Helio waits for slicing to finish.** If the plate hasn't been sliced, or has no G-code to send, Helio tells you instead of starting.

### 🔄 More reliable uploads and downloads

Assess and Enhance now handle unexpected responses from the Helio service cleanly instead of failing. Downloading G-code from Helio History now shows an error if the file can't be saved (for example, if your disk is full), instead of falsely reporting success.

## 🐛 Bug Fixes

- **Fixed a crash when changing the printer while Helio was processing.**
- **Fixed broken links in Assess results.** The links now point to the updated Helio wiki pages.
- **Fixed numbering and layout in the project filaments panel.**

## ⚠️ Known limitation

- **Helio doesn't support plates with Mixed colour sublayer turned on.** This feature breaks the contact graph assumption Helio relies on. Helio now checks for it and stops before running, with a message explaining what to change. Turn the setting off and reslice to use Helio. [Read more](https://wiki.helioadditive.com/en/known-issues-null-values)

## 🚀 Want early access to experimental builds?

You can now see when Helio releases experimental builds and try them. If you only want stable releases, tick **Check for stable updates only** in the update dialog or in Preferences > Online.
